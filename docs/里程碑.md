## 2. M0：工程、设计与认证基线

### 目标

建立前端、后端和文档的正式目录，使新成员可以用固定命令安装、构建和测试。

### 工作项

#### 前端

- 创建 `frontend/`；
- 从 `xju-feiyue/frontend` 基线提交 `706eb373525dd7f92ea4032d38251378c3f04c6d` 复制：
  - `tokens.css`；
  - `globals.css`；
  - `prose-claude.css`；
  - Tailwind、PostCSS、TypeScript、Vite、ESLint、Prettier 和 shadcn 配置；
  - `cn.ts`、测试 setup 和必要 UI primitives；
- 创建精简 `package.json`；
- 使用 pnpm 生成锁文件；
- 复制飞跃 `LoginPage`、`LoginForm`、`authStore`、认证 Schema/Endpoint 和受保护路由模式；
- 保证 `pnpm dev`、`pnpm build`、`pnpm typecheck`、`pnpm lint`、`pnpm test:run` 可执行。

#### 后端

- 创建 Rust Cargo Workspace；
- 初始化 Axum、Tokio、SQLx SQLite；
- 创建 `/api/health`；
- 加入 tracing 和统一错误响应；
- 建立空迁移和测试数据库辅助代码。
- 定义 `FeiyueIdentityClient` 与 `AuthContext` 接口，不读取飞跃数据库、不持有其 JWT 密钥。

#### 仓库

- 添加 `.gitignore`，排除 SQLite、上传目录、构建产物和虚拟环境；
- 添加根目录 Makefile 或等价任务入口；
- 建立前后端 CI；
- 记录前端复用来源。
- 固化飞跃 `/auth/me`、`is_lab_member`、超级管理员映射和 huawei2 部署契约。

### 交付物

- `frontend/` 可构建应用；
- `backend/` 可启动 API；
- `pnpm-lock.yaml`；
- `Cargo.lock`；
- 第一版 CI；
- 前端复用记录。
- [认证与部署集成方案](认证与部署集成.md)。

### 退出条件

```bash
cd frontend
pnpm install --frozen-lockfile
pnpm typecheck
pnpm lint
pnpm test:run
pnpm build

cd ../backend
cargo fmt --all --check
cargo clippy --workspace --all-targets --all-features -- -D warnings
cargo test --workspace
```

以上命令全部通过，`GET /api/health` 返回成功，才完成 M0。

- 支持外链与上传文件；
- 实现文件类型、MIME 和文件头校验；
- 实现受权限控制的下载；
- 记录来源者、更新时间和可用性状态。

#### 导入

- 创建 `import_jobs` 和 `import_items`；
- 实现简介提示、链接和附件混合收集；
- 实现压缩包展开、文件索引与资源分类；
- 实现 Codex 结构化草稿、人工补充提示和确定性 fallback；

- 导入确认使用短事务；

## 6. M4：权限、审计与 Agent

### 目标

建立内部管理边界，并提供可引用、不可擅自写数据的 Agent 问答。

### 工作项

#### 权限

- 固化访客、飞跃普通用户、实验室成员、项目负责人和飞跃超级管理员；
- 只有飞跃超级管理员可以修改实验室成员标记；
- 飞跃 `admin` 不自动获得 ICTHub 管理权限；
- 公开与内部项目可见性；
- 项目写权限；
- 资源下载权限；
- 管理入口保护；
- 关键写操作审计日志。

#### Agent

- 创建 Agent Provider trait；
- 接入一个外部模型供应商；
- 实现项目搜索工具；
- 实现项目详情与资源摘要工具；
- 回答中返回项目/资源引用；
- 首期只读；
- 写操作只生成草稿，不直接执行；
- 记录耗时、工具调用和引用对象。

### 测试

- 角色权限矩阵；
- 未授权写接口；
- 内部资源下载；
- Agent 工具参数校验；
- Agent 无引用回答的降级；
- 模型超时和错误处理；
- Agent 不可直接写数据库。
- 超级管理员成员标记接口和 UI 权限；
- 飞跃认证不可用时的公开读/受保护写降级。

### 交付物

- 实验室成员与项目级权限；
- 飞跃超级管理员成员标记能力；
- 审计日志；
- Agent 问答入口；
- 至少五类可验证问题模板。

### 退出条件

- 所有写接口均有权限测试；
- Agent 回答包含可点击引用；
- 模型不可用时不影响项目 CRUD；
- Agent 无法绕过应用服务执行任意 SQL；
- 敏感信息不进入模型日志。

## 8. 跨里程碑 Definition of Done

任何工作项标记完成前必须满足：

- 功能与当前文档一致；
- 有对应测试或说明为何无需测试；
- 前端 TypeScript 无错误；
- ESLint 无错误；
- Rust fmt、clippy、test 通过；
- 数据库变更具有迁移；
- 用户可见变更具有截图或 E2E；
- 新依赖说明用途；
- Python 依赖由 uv 锁定；
- 文档、OpenAPI 和代码行为同步；
- 不提交 SQLite 数据文件、上传文件、密钥、`node_modules` 或虚拟环境。
